# Contribution and AI assistance

Arash Amini initiated and owns the project, selected the portfolio objective,
reviewed the proposed direction and created the public GitHub repository.

The initial implementation was generated with AI assistance. The primary agent
coordinated scope, architecture, integration, interface and deployment. A machine
learning specialist implemented and trained the reproducible research pipeline.
A separate audit agent inspected the code, ran independent correctness and
retraining probes, and reported findings for correction. A research agent checked
the external dataset source and acquisition constraints.

These AI roles are not human employees or independent third-party certifications.
The repository records executable evidence rather than treating role titles as
validation. Before presenting this as a personal research contribution, the owner
should be able to explain the simulator assumptions, temporal split, feature
contract, model tradeoffs and limitations. Future owner-authored experiments
should be recorded in commit history and the experiment report.
